# خطة تحسين إحصائيات استهلاك المشترك والتحليل الذكي

سأقوم بتطوير نظام تحليل الاستهلاك في NetMaster Pro ليتحول من مجرد أرقام ثابتة إلى واجهة معلوماتية تفاعلية تتبع كل حركة للمستخدم بدقة.

### 1. الهندسة البيانية والذكاء الاصطناعي (Data Analysis)
*   **خوارزمية تصنيف الاستهلاك (Smart Categorization):** نظرًا لأن MikroTik لا يزودنا بأسماء التطبيقات مباشرة، سأقوم ببرمجة محرك تحليل يعتمد على أنماط استهلاك البيانات في الجلسات (Payload Patterns) لتقدير الاستهلاك حسب الفئات:
    *   **فيديو:** (YouTube, TikTok, Netflix).
    *   **تواصل اجتماعي:** (Facebook, Instagram, WhatsApp).
    *   **ألعاب وتحميل:** (App Store, Gaming).
    *   **تصفح عام.**
*   **تتبع الجلسات التراكمي:** ربط كافة سجلات الـ Archive مع بيانات الراوتر الحالية لبناء ملف استهلاك "Lifetime" متكامل.

### 2. تحديث واجهة تفاصيل المشترك (UI Redesign)
*   **شبكة البطاقات الأربع (4-Card Grid):** إعادة تصميم قسم الاستهلاك ليعرض 4 بطاقات تفاعلية:
    1.  **الإجمالي الكلي:** (التحميل + الرفع).
    2.  **إجمالي التحميل.**
    3.  **إجمالي الرفع.**
    4.  **الوقت التراكمي.**
*   **التفاعل:** تحويل كافة البطاقات إلى أزرار ذكية تنقلك إلى "مركز تحليل البيانات".

### 3. شاشات التحليل التفصيلية (Dedicated Analytics Screens)
*   **شاشة الإحصائيات المتقدمة:** بناء شاشة كاملة لكل نوع استهلاك تشمل:
    *   **الرسوم البيانية:** استخدام مكتبة `Vico` لعرض منحنيات الاستهلاك الزمني (Consumption Trends).
    *   **توزيع التطبيقات:** عرض "Doughnut Chart" يوضح نسبة استهلاك كل تطبيق (يوتيوب، فيسبوك، إلخ).
    *   **سجل الحركات:** جدول زمني مفصل لكل ميجابايت تم استهلاكها وفي أي وقت.

### 4. التنفيذ البرمجي (Implementation Steps)
1.  **تعديل `NavRoutes.kt`:** إضافة مسار `UsageAnalytics(username, type)`.
2.  **تطوير `MainViewModel.kt`:** إضافة منطق توليد "Smart Usage Snapshot".
3.  **تعديل `UserDetailDialog.kt`:** تحويل العرض إلى شبكة البطاقات الأربع وربطها بالملاحة.
4.  **إنشاء `UsageAnalyticsScreen.kt`:** بناء واجهة الرسوم البيانية والتحليل الذكي.
