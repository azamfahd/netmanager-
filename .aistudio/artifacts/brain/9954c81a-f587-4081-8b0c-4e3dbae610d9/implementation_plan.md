# خطة عمل تطوير شاشة طباعة وتخصيص الكروت (VoucherPrintScreen)

تهدف هذه الخطة إلى ترقية واجهة طباعة وتخصيص الكروت لتوفير تجربة احترافية ومتقدمة تتيح للمستخدم تقسيم الشاشة إلى جزأين، تخصيص صور الخلفيات من المعرض، والتحكم بدقة في مواقع وأحجام النصوص (رقم الكرت، كلمة المرور) على قالب الكرت.

---

### 1. المتطلبات والتحسينات الأساسية

1. **تصميم الشاشة بنظام الشق المزدوج (Side-by-Side Split Screen)**:
   - تقسيم الشاشة إلى قسمين رئيسيين (في الأجهزة العريضة أو الوضع الأفقي):
     - **القسم الأيمن / العلوي**: لوحة الإعدادات والتحكم والتخصيص (اختيار صورة الخلفية، التحكم بالإزاحة الأفقية والعمودية، حجم الخط، إظهار/إخفاء كلمة المرور، وتنسيق القالب).
     - **القسم الأيسر / السفلي**: معاينة حية تفاعلية ودقيقة للكروت بناءً على التخصيصات المطبقة.
   - دعم التجاوب الكامل (Responsive Design) مع الشاشات الصغيرة والهواتف المحمولة (عبر تبديل تلقائي أو تبويبات سلسة).

2. **أدوات تحكم متقدمة لتخصيص النصوص**:
   - **منتقي الصور من المعرض**: اختيار صورة خلفية مخصصة للكروت عبر منتقي الصور الحديث في أندرويد.
   - **مؤشرات الإزاحة (Position Sliders)**:
     - إزاحة أفقية (X Offset: تحريك النص يمين أو يسار).
     - إزاحة عمودية (Y Offset: تحريك النص لأعلى أو لأَسفل).
   - **التحكم بحجم الخط (Font Size Scale)**: تكبير أو تصغير حجم رقم الكرت والنص المعروض بدقة.
   - **تبديل كلمة المرور (Password Display Toggle)**: خيار لإظهار أو إخفاء كلمة المرور بجانب رقم الكرت أو تحته.

3. **معاينة حية فورية (Live Preview)**:
   - عرض نموذج حقيقي للكرت مع تطبيق الخلفية المخصصة والإحداثيات (الإزاحة وحجم الخط) مباشرة أثناء تحريك المؤشرات.

---

### 2. خطوات التنفيذ التقنية

1. **تحديث حالة الـ ViewModel / State في `VoucherPrintScreen.kt`**:
   - إضافة حالات (State) جديدة لإدارة:
     - مسار صورة الخلفية المخصصة (`customBgUri`).
     - إحداثيات الإزاحة الأفقية والعمودية (`textOffsetX`, `textOffsetY`).
     - حجم الخط (`textFontSize`).
     - خيار إظهار كلمة المرور (`showPasswordOnCard`).

2. **تطوير واجهة الشق المزدوج (`SplitScreenLayout`)**:
   - استخدام `Row` للشاشات العريضة/الأجهزة اللوحية و`Column` للشاشات الصغيرة مع تقسيم متناسق (وزن 1:1 أو 1:1.5).

3. **تنفيذ معاينة الكرت المخصصة (`CustomCardPreviewItem`)**:
   - رسم خلفية الكرت (صورة مخصصة أو لون متدرج افتراضي).
   - تطبيق إحداثيات الإزاحة (`Modifier.offset(x = ..., y = ...)`) وحجم الخط على نصوص رقم الكرت وكلمة المرور وبقية التفاصيل.

---

### 3. معايير النجاح والتحقق
- سلاسة التفاعل مع أدوات التحكم والإزاحة دون أي تأخير أو وميض.
- عرض النصوص (رقم الكرت وكلمة المرور) بدقة فوق الصورة المختارة من المعرض وفق الإحداثيات المحددة.
- نجاح بناء المشروع وتجميعه دون أخطاء (`compile_applet`).
