# NetManager — نظام إدارة شبكات ميكروتك وكروت الهوتسبوت

تطبيق أندرويد متكامل واحترافي باللغة العربية لإدارة شبكات ميكروتك (MikroTik RouterOS) ومتابعة المستخدمين النشطين وإصدار وإدارة كروت الهوتسبوت، مبني بأحدث تقنيات Jetpack Compose و Material Design 3.

---

## 🚀 المميزات الرئيسية

- **التعرف التلقائي على الراوتر (Auto-Discovery)**: يكتشف عنوان بوابة الراوتر (Gateway IP) والمنفذ تلقائياً بمجرد اتصال الهاتف بالشبكة.
- **تسجيل دخول مباشر**: إدخال اسم المستخدم وكلمة المرور فقط للاتصال.
- **متابعة المستخدمين النشطين (Live Active Users)**: عرض المتصلين في الوقت الفعلي مع تفاصيل الاستهلاك (IP, MAC, Uptime, Bytes In/Out) وإمكانية طرد أي مستخدم بنقرة واحدة.
- **توليد كروت الهوتسبوت بالجملة (Batch Voucher Generator)**: توليد كروت بأرقام عشوائية أو أرقام وحروف، كود موحد أو منفصل، مع تحديد الباقة والمهلة وسعة البيانات والسعر، وحفظها مباشرة في الراوتر.
- **معاينة وطباعة وتصدير الكروت (Print & Share)**: عرض الكروت في شبكة تصميم كروت جاهزة للطباعة والتوزيع مع الباركود التزييني والسعر.
- **إدارة باقات السرعة (Hotspot Profiles)**: إنشاء واستعراض باقات السرعات والتحميل والرفع وعدد الأجهزة لكل كرت.
- **أدوات الشبكة**: فحص الاستجابة (Ping Tool)، عرض الأجهزة المعفاة (IP Bindings)، وإعادة تشغيل الراوتر (Reboot).

## 📦 البناء التلقائي عبر GitHub Actions

يحتوي هذا المستودع على سير عمل مؤتمت بالكامل (`.github/workflows/build-apk.yml`):

1. بمجرد دفع أو مزامنة الكود إلى مستودع **GitHub** (على فرع `main` أو `master`):
   - يتم تشغيل **GitHub Actions** تلقائياً.
   - يتم إعداد بيئة Java 17 و Gradle وبناء وتجميع ملف الـ APK.
   - يتم رفع ملف التطبيق الجاهز كـ **Artifact** باسم `NetManager-APK`.
2. يمكنك تنزيل ملف الـ APK مباشرة من تبويب **Actions** في مستودع GitHub الخاص بك وتثبيته فوراً على أي هاتف أندرويد.
3. عند إنشاء وسم إصدار جديد (مثل `v1.0.0`)، يتم إنشاء **GitHub Release** تلقائياً مع إرفاق ملف `NetManager-Mikrotik-Manager.apk` للتحميل المباشر.

## 🛠️ متطلبات الراوتر
- راوتر MikroTik يعمل بنظام RouterOS v7.x أو v6.x.
- التأكد من تفعيل خدمة `www` (المنفذ 80) من خلال:
  `IP -> Services -> www -> Enabled` (مفعلة افتراضياً في معظم الراوترات).
